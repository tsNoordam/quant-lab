# Extract Paper

Follow this workflow:

1. Locate the paper.
2. Read the complete paper.
3. Extract research question.
4. Extract hypothesis.
5. Extract dataset.
6. Extract equations.
7. Extract variables.
8. Extract methodology.
9. Extract empirical results.
10. Extract assumptions.
11. Extract limitations.
12. Create an evidence matrix.

Write results to:

research/extraction/
research/equations/
research/methodology/
research/assumptions/
research/evidence/

Never design the trading strategy during this phase.
